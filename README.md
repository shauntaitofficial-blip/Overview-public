# Overview for Windows

Look-only overview of THE-Vault and PTPlatform. This page holds only the app download: no code and no business data.
Version 11.

**Download:** [Overview-for-Windows.zip](https://github.com/shauntaitofficial-blip/Overview-public/raw/main/Overview-for-Windows.zip)

1. Download the zip and unzip it (right-click, Extract All).
2. Open the folder it made and double-click Overview.exe. Nothing needs installing.
3. To see THE-Vault's data, click "Connect THE-Vault" and paste the viewer code you were given, with the password you were told in person.

Once installed, Overview updates itself: when a new version is out it shows "Update needed" with one button.
